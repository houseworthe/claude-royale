# 2v2 Mode - Co-op with Ethan

**Purpose:** Play 2v2 battles alongside Ethan (project supervisor).

---

## How It Works

1. Ethan sends a 2v2 invite from his device
2. Claude sees notification: "ehouse is looking for a 2v2 battle"
3. Claude taps the 2v2 accept button AND spawns 3 player agents simultaneously
4. Play the match normally
5. After match ends, return to main menu

---

## Spawn Protocol (2v2)

**When user says "2v2 mode":**

1. Take a screenshot
2. If you DON'T see "ehouse is looking for a 2v2 battle" notification:
   - Wait 5 seconds (`sleep 5`)
   - Screenshot again
   - Repeat until you see the notification
3. Once you see the notification, proceed with spawn protocol below

**When you see "ehouse is looking for a 2v2 battle" notification:**

In a SINGLE MESSAGE, spawn everything in parallel:

```
MESSAGE 1 - ALL IN PARALLEL:
  Bash (background): ./scripts/tap.sh 2v2_accept
  Bash (background): ./scripts/tap.sh 2v2_opener   <-- Auto-plays opening cards after 8s
  Task (background): player-2v2 subagent
  Task (background): player-2v2 subagent
  Task (background): player-2v2 subagent

THEN:
  Wait 60 seconds
  Poll agents with TaskOutput tool
  Repeat every 60 seconds until agents complete
```

**What `2v2_opener` does:**
- Waits 8 seconds for match to load
- Plays slot 1 to left lane (2G)
- Plays slot 2 to right lane (7G)
- This matches 1v1 auto-opener behavior

Subagents are pre-defined in `.claude/agents/player-2v2.md` - no prompt injection needed.

## Troubleshooting: Accept Button Not Working

If Claude isn't tapping the 2v2 accept button correctly, the coordinates may need recalibration.

**To recalibrate:**
1. Have Ethan send a 2v2 invite (so the notification is visible)
2. Run: `./scripts/calibrate-button.sh 2v2_accept`
3. Position your mouse over the Accept/Join button on the notification
4. Press ENTER to record the new coordinates
5. Test with: `./scripts/tap.sh 2v2_accept`

The notification appears at different positions depending on game state, so recalibration may be needed periodically.

## 2v2 Differences from 1v1

- **Auto-opener:** Use `tap.sh 2v2_opener` to auto-play opening cards (same as 1v1)
- **Play further back:** Default to rows F-G-H, not row E
- **Spread the battlefield:** Don't let everything cluster at the bridge
- **No trophy change:** 2v2 doesn't affect trophy count
- **Teammate:** Ethan plays alongside you
- **Result screen:** Same as 1v1, use `result_ok` to dismiss
